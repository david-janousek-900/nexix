# Nexix manual pages

All 307 V7 manual distribution files (sections 0–8) are installed unchanged
under `/usr/man`. Traditional vi/ex/view pages are additional section 1 pages.

These are historical reference manuals. Presence of a manual does not mean its
program or every documented interface has been ported. Consult `docs/tasks.md`
and `docs/v7-userland-manifest.json` for native implementation status. Nexix uses
x86_64 ELF executables, native 64-bit interfaces and native device drivers rather
than PDP-11 executable formats and hardware. Networking is planned for 0.2.0.
Native file times retain V7 atime/mtime/ctime semantics; there is no birth time.
The kernel initializes epoch time from RTC; libc applies the configured timezone.

Formatter tables are regenerated by `tools/formatter_tables.py` from the twelve
original terminal-table and twenty-five font-table C sources. Terminal data uses
an `NXTERM1` header, nine little-endian 32-bit metrics, and length-prefixed strings;
font data is exactly 224 width bytes. Neither format contains object headers or
pointers. The original mkfont/chars helper logic is also built for Nexix, with
modern initializer syntax, explicit character pairs and bounded width input.

The active formatter sources live in `user/troff`, derived from
`reference/v7/usr/src/cmd/troff`. The native port replaces the contiguous global
"environment block" assumption with an explicit structure, sizes macro call
frames and argument pointers for x86_64, uses mutable six-placeholder temporary
names, and initializes device tables before calculating character widths.
Macro parsing, registers, diversions, filling and line/page layout remain the V7
implementation. The formatter's private `atoi` parser is namespaced separately
from libc.

Task 281 installs the original tmac macro packages, yacc parser template, lex
scanner template and lint library descriptions without changing their contents.
The parser-generator, scanner-generator and lint implementation tasks still own
retargeting those descriptions for their future native consumers.

`nroff` defaults to the line-printer table (`-Tlp`) for readable VGA/ANSI output;
all original terminal tables remain selectable with `-Tname`. All 301 files in
manual sections 1–8 are rendered in the native acceptance test at 16/128 MiB.
When using `-man`, includes of historical `/usr/include/...` text are resolved
from unchanged archival excerpts under `/usr/man/include`. These excerpts are
historical documentation, not native development headers. Other formatter use
continues to read the requested include paths normally.
