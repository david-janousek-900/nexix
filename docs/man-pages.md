# Nexix manual pages

All 307 V7 manual distribution files (sections 0–8) are installed under
`/usr/man`, unchanged except for system binary paths: seven pages (`init(8)`,
`getty(8)`, `update(8)`, `crash(8)`, `mknod(1m)`, `wall(1m)` and `sa(1m)`) name
the BSD locations, such as `/sbin/init`, instead of V7's `/etc` (task 432).
`make test-man-pages` checks that each differs from its original by exactly
those paths. Traditional vi/ex/view pages are additional section 1 pages.

These are historical reference manuals. Presence of a manual does not mean its
program or every documented interface has been ported. Consult `docs/tasks.md`
and `docs/v7-userland-manifest.json` for native implementation status. Nexix uses
x86_64 ELF executables, native 64-bit interfaces and native device drivers rather
than PDP-11 executable formats and hardware. Networking is planned for 0.2.0.
Native file times retain V7 atime/mtime/ctime semantics; there is no birth time.
The kernel initializes epoch time from RTC; libc applies the configured timezone.

Formatter tables are regenerated by `tools/formatter_tables.py` from the twelve
original terminal-table and twenty-five font-table C sources. Terminal data uses
an `NXTERM1` header, nine little-endian 32-bit metrics, and length-prefixed strings;
font data is exactly 224 width bytes. Neither format contains object headers or
pointers. The original mkfont/chars helper logic is also built for Nexix, with
modern initializer syntax, explicit character pairs and bounded width input.

The active formatter sources live in `user/troff`, derived from
`reference/v7/usr/src/cmd/troff`. The native port replaces the contiguous global
"environment block" assumption with an explicit structure, sizes macro call
frames and argument pointers for x86_64, uses mutable six-placeholder temporary
names, and initializes device tables before calculating character widths.
Macro parsing, registers, diversions, filling and line/page layout remain the V7
implementation. The formatter's private `atoi` parser is namespaced separately
from libc.

Task 281 installs the original tmac macro packages, yacc parser template, lex
scanner template and lint library descriptions without changing their contents.
The parser-generator, scanner-generator and lint implementation tasks still own
retargeting those descriptions for their future native consumers.

`nroff` defaults to the line-printer table (`-Tlp`) for readable VGA/ANSI output;
all original terminal tables remain selectable with `-Tname`. All 301 files in
manual sections 1–8 are rendered in the native acceptance test at 16/128 MiB.
When using `-man`, includes of historical `/usr/include/...` text are resolved
from unchanged archival excerpts under `/usr/man/include`. These excerpts are
historical documentation, not native development headers. Other formatter use
continues to read the requested include paths normally.

`troff -a` produces its historical plain-text approximation; `troff -t` writes
C/A/T typesetter bytes to standard output. Mounted fonts use the regenerated
224-byte width files without an object header. `make test-troff` checks ASCII
output, mounted fonts, size changes, original manual macros and independently
validated C/A/T initialization/stop/padding/flush framing at 16/128 MiB.

The original `eqn` grammar and equation-layout code are ported under `user/eqn`.
Semantic values can hold native pointers as well as register numbers. Diagnostics
use native varargs; movement arguments and an unsequenced parenthesis calculation
are corrected. The parser is regenerated with a host-only bootstrap of the V7
yacc sources (`tools/v7-yacc`); the native yacc tasks remain separate. Equation
acceptance covers fractions, roots, powers, sums, delimiters, matrices, definitions,
inline equations, movement and formatter integration at both memory sizes.

The distinct V7 terminal-equation sources are retained under `user/neqn` with
the same pointer/diagnostic/parser adaptations. `neqn` output feeds `nroff`;
`eqn` output feeds `troff`. The respective reference implementations' layout
choices and supported syntax are retained.

`tc` retains the V7 C/A/T-to-Tektronix 4014 converter for historical `man -k`
and `man -ek` modes. Those modes produce Tektronix graphics protocol, not keyword
search results or ANSI text. Use `tc -t` for noninteractive captures. Acceptance
checks generated protocol with page/scale options; a Tektronix terminal/emulator
is needed to display it graphically. Normal `man` output uses the text pager.

## Reading manuals

Use `man ls`, `man 2 read`, `man 3 printf`, `man uptime` or `man 7 nexix`.
The installed original script is adapted to select `more` on VGA/serial terminals.
Use Space/b or Page Down/Up for pages, j/k or arrow keys for lines, g/G for
beginning/end, /text or ?text to search, n/N to repeat/reverse, and q to quit.
Search is literal and case-sensitive. See [pager behavior](pager.md).
`MANPAGER` overrides `PAGER`; redirected output bypasses the pager.

`man -w name` retains V7's relative source-path output. Missing pages return 1;
invalid empty invocations return 2. Section 0 front matter is selected explicitly,
for example `man 0 intro`, and uses `-ms` (the permuted index loads ptxmac first).
Section 0 and other sections must be requested separately. Original sections
1–8 use `-man`; section 1 includes historical suffixes such as `.1m`.

The original formatter selections are retained. `-ne` invokes neqn/nroff and
`-e` invokes eqn/troff. Native `-t`/`-e` write C/A/T bytes to standard output
for capture instead of implicitly opening a physical typesetter. Non-terminal
`-k`/`-ek` captures make tc noninteractive; terminal previews retain its
interactive behavior. These are historical Tektronix modes, not modern keyword
search options. The script still has V7 pipeline semantics for optional
preprocessors; the text formatter/pager adapter checks both of its child statuses.

Manuals describe historical interfaces. `/usr/man/README` and `man 7 nexix`
provide native annotations without changing the original pages. The formatter's
date registers now follow libc timezone handling rather than a fixed EST offset;
the historical year-register representation remains years since 1900.

`make test-manuals` runs the complete manual/data/formatter/pager/frontend
acceptance group. `make test-man` focuses on installed lookup, formatter modes
and login-session VGA/serial navigation. Tests use disposable images.
