# UNIX V7 reference source

Baseline: TUHS's Henry Spencer V7 distribution:
https://www.tuhs.org/Archive/Distributions/Research/Henry_Spencer_v7/v7.tar.gz

Downloaded archive SHA-256:
`e0fd7bdd046e17de177f5d997acf8123fa43c57b46b032c7337f7666ab69a07e`

`v7/` retains the archive's `usr/sys/` kernel and `usr/src/` userland source
trees without source edits. Historical binaries and unrelated distribution
files are not imported. Preserve this reference; perform porting in separate
active source directories.

The historical UNIX license is retained as `Caldera-license.pdf` alongside this
file. Its terms apply to the historical sources; do not assume that provenance
grants a license for unrelated additions.
